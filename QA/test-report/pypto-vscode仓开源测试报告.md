# pypto-vscode仓开源测试报告
## 1. 概述
本报告为PyPTO Toolkit插件开源测试报告，在该阶段完成了基于PyPTO Toolkit 2.1.0版本开源包的测试，覆盖所有功能特性及文档，测试过程中执行覆盖率达到100%。

PyPTO Toolkit是一款PyPTO框架全流程辅助工具，提供包括编译、运行时状态的可视化、算子开发工作流的作业能力，使能开发者快速建立对PyPTO框架的理解，提升算子开发和调试调优效率。

## 2. 版本测试信息

- 操作系统：Windows/Linux
- IDE版本：Visual Studio Code>=1.94.1
