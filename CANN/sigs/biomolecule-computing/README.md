# Biomolecule Computing SIG

## 概述

Biomolecule Computing SIG（生物分子计算 SIG）是面向生命科学领域、负责建设昇腾原生算子库的开源兴趣小组，算子仓为 `bio-ops-molecule`。本 SIG 聚焦多组学数据处理、生物分子模拟和生物基础模型训练等场景，通过高性能行业算子解决计算效率、显存占用和数据访存等底层性能瓶颈。

## 工作目标（Goals）

- 建设生命科学高性能原生算子，解决超长序列推理、物理等变计算、稀疏数据访存和基因序列预处理等工程问题；
- 构建“物理机理 + 数据驱动”的加速底座，沉淀分子动力学、力场评估、自由能计算及生物特征编码等核心能力；
- 提供标准化算子与接口，推动生物医药、合成生物学和精准医疗应用在 CANN 生态落地。

## 工作愿景（Vision）

本 SIG 定位为昇腾生态面向生命科学行业的垂直算子中枢，连接通用算子与行业应用，构建兼顾物理规律、生物先验、计算性能和科学可解释性的自主算力底座。

## 目标场景（Fields）

- **生物分子机理模拟**：面向分子动力学、结构精修和分子对接，开发动力学积分、力场评估、自由能计算及机理约束类算子，提升复杂分子模拟的计算效率与精度；
- **生物分子预测与基础模型**：面向蛋白质结构预测、虚拟细胞和生物基础模型，开发长序列注意力及物理等变特征计算算子，降低超长序列计算的显存开销，提升特征提取与模型训练效率；
- **多组学与基因分析**：面向单细胞、多组学、基因序列早筛和辅助病理分析，开发稀疏特征提取、并行检索及基因组变异编码算子，提升稀疏数据访存效率与基因序列预处理吞吐。
